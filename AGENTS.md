# AGENTS.md

## Project Summary

**Forge** is an AI-native game engine and Windows Studio IDE designed for real-time collaboration between human creators and autonomous agent workflows.

- **Engine Core:** High-performance systems built in Rust leveraging `wgpu` for graphics and `bevy_ecs` for entity-component orchestration.
- **Studio IDE:** Desktop application built with Tauri 2, React 19, TypeScript, and Vite.
- **Agents & Tooling:** TypeScript runtime and packages powering autonomous workflows, code generation, and scene manipulation.

## Global Rules & Development Environment

1. **Activate Local Environment:**
   Every PowerShell terminal session must activate the repository toolchain:
   ```powershell
   . .\tools\dev-env.ps1
   ```
2. **Follow Git Workflow:**
   Never commit directly to `main`. Create branches from `main`, rely on CI for validation, open PRs, and squash merge when CI is green. See [git.md](file:///docs/agent-guides/git.md).
3. **Strict Folder Ownership:**
   Tasks only edit files in their designated sub-domain. See [parallel.md](file:///docs/agent-guides/parallel.md).
4. **Protocol First:**
   Cross-boundary IPC contracts must be updated in `packages/protocol/schemas/` first, followed by code generation (`pnpm run codegen`).
5. **Never Edit Generated Files:**
   Never hand edit files generated by compilers or build scripts (`packages/protocol/src/generated/*`, `crates/forge_protocol/src/generated.rs`, `templates/*/scripts/forge.d.ts`).
6. **Definition of Done (DoD):**
   - Clean workspace build (`cargo check --workspace`).
   - Clean lint and typecheck (`pnpm -r lint`, `pnpm -r typecheck`, `cargo clippy --workspace -- -D warnings`).
   - All tests passing in CI (`cargo nextest run`, `pnpm -r test`).
