# Parallel Workflows & Isolation Guide

## 1. Principles of Parallel Execution

To enable multiple autonomous agents and human developers to work concurrently across the Forge repository without stepping on each other or causing merge conflicts, strict isolation rules apply:

1. **Folder Ownership:**
   Every task strictly owns specific folders and must edit nothing else.
   - Task touching Engine: only `crates/` (excluding generated protocol code).
   - Task touching Studio: only `apps/studio/`.
   - Task touching Agent runtime: only `packages/agent/`.
   - Task touching Protocol schemas: only `packages/protocol/schemas/` and `packages/protocol/scripts/codegen.mjs`.
   - Task touching UI: only `packages/ui/` and `packages/tokens/`.
   - Task touching Docs: only `docs/`.

2. **Lockfile Conflicts:**
   Never hand edit lockfiles (`pnpm-lock.yaml`, `Cargo.lock`).
   - If a lockfile conflict occurs in `pnpm-lock.yaml`, resolve by re-running:
     ```powershell
     pnpm install
     ```
   - If in `Cargo.lock`, resolve by re-running:
     ```powershell
     cargo check
     ```

3. **Generated Files Are Never Hand Edited:**
   Files generated by compilers, code generators, or build scripts must never be manually altered:
   - `packages/protocol/src/generated/*`
   - `crates/forge_protocol/src/generated.rs`
   - `templates/*/scripts/forge.d.ts`
   Always edit the schema or generator script, then re-run:
   ```powershell
   pnpm run codegen
   ```

4. **Minimal Shared File Edits:**
   Shared files that affect the entire workspace must only receive minimal, surgical edits:
   - Root `Cargo.toml` / `Cargo.lock`
   - Root `package.json` / `pnpm-workspace.yaml` / `pnpm-lock.yaml`
   - `.github/workflows/ci.yml`: Changes to `.github/workflows` must be one-line additions only.

---

## 2. Guide Ownership Rules

Future tasks must only edit their own corresponding domain guide under `docs/agent-guides/`:
- Engine tasks edit `docs/agent-guides/engine.md`
- Studio tasks edit `docs/agent-guides/studio.md`
- Agent tasks edit `docs/agent-guides/agent.md`
- Protocol tasks edit `docs/agent-guides/protocol.md`
- Docs tasks edit `docs/agent-guides/docs.md`
- UI tasks edit `docs/agent-guides/ui.md`
- Git tasks edit `docs/agent-guides/git.md`
- Parallel process changes edit `docs/agent-guides/parallel.md`

`AGENTS.md` remains a stable, short index and global entry point.

---

## 3. Do and Do Not

### Do:
- Confine edits strictly to the directories assigned to your active prompt or issue.
- Re-run `pnpm run codegen` if modifying protocol contracts, and commit the generated outputs.
- Keep PRs scoped to single-domain responsibilities.

### Do Not:
- Do not make opportunistic "drive-by" refactorings outside your owned directories.
- Do not touch `.github/workflows/ci.yml` unless strictly required, and limit changes to single-line additions.
- Do not commit manual edits to generated code.
