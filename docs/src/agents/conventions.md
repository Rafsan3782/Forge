# Engine Conventions and Standards

AI agents must adhere to these exact conventions across scenes, scripts, and asset imports.

## 1. Coordinate System & Axis Directions

| Axis / Dimension | Direction | Description |
| :--- | :--- | :--- |
| **X Axis** | Left to Right | `+X` points rightward. `-X` points leftward. |
| **Y Axis** | Bottom to Top | `+Y` points upward (Cartesian standard). `-Y` points downward. Gravity vector points in `-Y` (e.g. `[0, -980]`). |
| **Rotation** | Counter-Clockwise | In radians. `0.0` points right along `+X`. `PI / 2` (1.5708) points up along `+Y`. |
| **Z Ordering** | Back to Front | Integer `z_index` on `Sprite`. Lower values render behind higher values. Background: `-100` to `-1`, Gameplay: `0` to `10`, Foreground/HUD: `50` to `100`. |

## 2. Units and Pixel Scales

| Unit Category | Standard Unit | Value in 2D Space |
| :--- | :--- | :--- |
| **World Position** | Pixels | 1 unit = 1 screen pixel at default camera zoom `1.0`. |
| **Tile Size** | Pixels | Standard tiles are `16x16` or `32x32` pixels. |
| **Time** | Seconds | `dt` in `onUpdate(dt)` is in seconds (float). Frame step is ~`0.016667` s. |
| **Velocity** | Pixels / Second | `px/s`. Typical run speed: `150` to `250 px/s`. Jump velocity: `350` to `500 px/s`. |
| **Gravity** | Pixels / Second² | `px/s²`. Standard 2D gravity is `800` to `1200 px/s²` downward. |
| **Volume** | Linear Gain | `0.0` (mute) to `1.0` (full scale). Master bus defaults to `1.0`. |

## 3. Project Directory Structure

Every Forge game project follows this standardized folder layout:

```text
my-project/
├── .forge/                       # Project local cache & bridge session info
├── assets/                       # Raw assets and sidecar metadata
│   ├── hero.png                  # Sprite texture
│   ├── hero.png.meta.json        # Asset metadata sidecar
│   ├── jump.wav                  # 16-bit uncompressed WAV sound
│   ├── jump.wav.meta.json        # Audio metadata sidecar
│   ├── tileset.json              # Tilemap palette definition
│   └── tileset.png               # Tileset texture atlas
├── scripts/                      # TypeScript gameplay scripts
│   ├── forge.d.ts                # TypeScript global typings (auto-generated)
│   ├── tsconfig.json             # TypeScript compiler settings
│   ├── player.ts                 # Hero controller script
│   └── camera.ts                 # Camera follower script
├── input_map.json                # Action to key/button binding definitions
└── scene.json                    # Serialized root scene
```

## 4. Asset References and Identifiers

1. **Asset IDs:** Every asset is referenced by its relative path or assigned UUID string (e.g. `"hero.png"` or `"assets/hero.png"`).
2. **Sidecar Files:** Every file in `assets/` has a corresponding `<filename>.meta.json` generated by `asset.import`. Do not edit UUIDs inside sidecars manually.
3. **Audio Format:** `forge_audio` currently plays uncompressed 16-bit PCM `.wav` files. Do not import `.mp3` or `.ogg` without converting to `.wav`.
