# AGENTS.md

Rules and operational conventions for autonomous agents working within this project.

## How to Run Checks

1. **Type Checking**:
   Run TypeScript validation on scripts:
   ```powershell
   forge check
   ```
2. **Deterministic Map Indexing**:
   Re-index the project assets, scenes, and components:
   ```powershell
   forge index
   ```
3. **Headless Smoke Test**:
   Execute 1 frame headlessly to verify scene loading:
   ```powershell
   forge run templates/platformer/scene.json --headless
   ```

## Naming & Code Conventions

- **Scripts**: PascalCase class/component exports, camelCase lifecycle hooks (`onStart`, `onUpdate`, `onDestroy`).
- **Assets**: Lowercase snake_case files (e.g. `coin.png`, `player_sheet.png`, `jump.wav`).
- **Entities**: Descriptive title case entity names in `scene.json` (e.g. `Hero Player`, `World Tilemap`).

## What Not to Touch

- Do **not** hand-edit `scripts/forge.d.ts` (this is automatically generated by the engine compiler).
- Do **not** hand-edit `.forge/map.json` (always regenerate via `forge index`).
- Do **not** delete existing checkpoint coordinates in `scripts/player.ts` without migrating player respawn logic.
- Do **not** introduce external npm dependencies in `scripts/` without updating `tsconfig.json`.
